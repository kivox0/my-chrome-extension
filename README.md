# Rent Radius

Расширение для Chrome, которое помогает искать жильё рядом с нужным местом. Открываешь сайт аренды, вводишь свой адрес и радиус в километрах, и расширение выделяет на странице только подходящие варианты.

## Что умеет
- Работает на сайтах аренды жилья
- Принимает адрес и радиус поиска в км
- Выделяет объявления, которые попадают в этот радиус

## Как установить
1. Скачай репозиторий (Code → Download ZIP) и распакуй
2. Открой в Chrome `chrome://extensions`
3. Включи «Режим разработчика» (справа вверху)
4. Нажми «Загрузить распакованное расширение» и выбери папку

## Как пользоваться
1. Открой сайт аренды
2. Нажми на иконку расширения
3. Введи адрес и радиус в км
4. Подходящие варианты будут выделены на странице

## Технологии
HTML, CSS, JavaScript
